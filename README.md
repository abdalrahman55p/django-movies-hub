# 🎬 Django Movies Hub

A full-stack web application built with Django for streaming and managing movies and series, featuring user role permissions and dynamic theme customization.

---

## 🌟 Key Features

* **Guest Access (Public View):**
  * Browse movies, series, and search the platform freely without logging in.
  * Restricted permissions: Guests cannot add or modify any content.

* **User Authentication & Management:**
  * Login system to unlock content creation privileges (adding new series and videos).
  * User profile settings with custom avatar uploads.

* **Dynamic UI & Customization:**
  * Full theme customization (Switch between Dark Mode, Light Mode, and custom color accents).
  * Personalize the web interface based on user preferences.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite (Development)

---

## 📌 مميزات المشروع (باللغة العربية)

* **صلاحيات الزوار:** تصفح والبحث عن المسلسلات والأفلام بحرية دون الحاجة لتسجيل الدخول (مع منع إضافة أو تعديل أي محتوى).
* **إدارة الحسابات:** إمكانية تسجيل الدخول لإضافة مسلسلات وفيديوهات جديدة، مع لوحة إعدادات لشخصنة الحساب وتغيير صورة البروفايل.
* **تخصيص الواجهة:** إمكانية تغيير ألوان الموقع والتبديل بين الوضع المظلم والفاتح حسب رغبة المستخدم.
